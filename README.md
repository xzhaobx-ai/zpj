# 赵雪莲个人作品集

React + Vite 单页作品集。内容来自提供的简历与两份作品集，联系方式与经历以最新简历为准。

## 本地运行

安装 Node.js 22.13 以上版本，在此目录运行：

```sh
pnpm install
pnpm dev
```

打开 http://127.0.0.1:5173/ 。`pnpm build` 生成 `dist`，`pnpm start` 预览构建结果。

## 后续调整

- `src/main.jsx`：个人介绍、经历、项目、能力及联系方式。
- `src/style.css`：颜色、版心、排版与响应式布局。
- `public/assets`：从作品集提取的图片与首页抽象循环视频。
- 项目卡片打开支持键盘关闭的详情弹层；邮件、电话使用系统应用，微信按钮复制账号。
- AI 设计以探索方向展示，未虚构 AI 项目、业务增长指标或工作经历。

主版心最大 1700px。视频为程序生成的抽象几何动态素材，静音循环，带暂停开关与减少动态效果支持，可直接替换 `hero.mp4` 和 `hero-poster.jpg`。
